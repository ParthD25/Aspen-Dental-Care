# Aspen Dental Care - Public Showcase

This repository is the public-facing showcase for Aspen Dental Care.

It is built for presentation: launch visuals, animated front page, and live-site screenshots. Private source code stays in the private repository.

## What is inside

- Animated portfolio-style front page
- Branded layout optimized for desktop and mobile
- Live website screenshot capture with a delay to prevent blank images
